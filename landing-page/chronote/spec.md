# Chronote Landing Page - Design Specification

## Project Context
Chronote is a Mac-native time and behavior analysis app that doesn't just track time - it explains it. The landing page must communicate this unique value proposition with premium, indie Mac app aesthetics.

## Design System

### Color Palette (NO BLUE/PURPLE)
- **Primary Background**: #0A0A0A (Deep Black)
- **Secondary Background**: #141414 (Charcoal)
- **Card Background**: #1A1A1A (Dark Grey)
- **Primary Accent**: #F59E0B (Amber/Gold - warmth, intelligence)
- **Secondary Accent**: #FBBF24 (Light Amber)
- **Text Primary**: #FFFFFF
- **Text Secondary**: #A1A1AA (Zinc-400)
- **Text Muted**: #71717A (Zinc-500)
- **Border**: #27272A (Zinc-800)
- **Success/Highlight**: #10B981 (Emerald - for productivity gains)

### Typography
- **Headings**: Inter or SF Pro Display (system font fallback)
- **Hero Title**: 72-80px, font-weight 700, letter-spacing -0.02em
- **Section Titles**: 48px, font-weight 600
- **Body**: 18px, font-weight 400, line-height 1.6
- **Small/Labels**: 14px, font-weight 500

### Layout
- **Max Width**: 1280px container
- **Section Padding**: 120px vertical
- **Grid**: 12-column with 24px gutters
- **Border Radius**: 12px (cards), 8px (buttons), 16px (large elements)

## Hero Section (VIDEO-LED)
- Full viewport height (100vh)
- Background: Atmospheric video showing abstract time visualization, flowing particles/data streams
- Video style: Dark, moody, cinematic with amber/gold particle effects
- Massive headline overlay: "Chronote doesn't just track time. It explains your time."
- Subheadline: Brief value prop
- CTA: "Download for Mac" button (amber accent)
- Secondary CTA: "Watch Demo"
- Floating app mockup or subtle UI preview

## Video Prompt (Hero)
"Cinematic abstract visualization of time and data flowing through space, dark background with warm amber and gold glowing particles forming patterns, slow motion data streams, Shot on Arri Alexa, 35mm lens, f/1.8 shallow depth of field, hyper-realistic lighting, 8k quality, subtle lens flares, volumetric lighting through particle streams"

## Sections

### 1. Problem Statement
- "You're busy all day. But where did the time go?"
- Relatable pain points with icons
- Dark cards with subtle borders

### 2. Solution/Features (4-5 Features)
- Behavioral Blocks
- Time Structure Analysis
- Pattern Recognition
- Narrative Explanations
- Mac Native Experience
- Each with icon, title, description

### 3. How It Works
- 3-step horizontal flow with connecting lines
- Step 1: Install & Run
- Step 2: Work Naturally
- Step 3: Understand Your Time

### 4. Differentiator
- Side-by-side comparison: Traditional Trackers vs Chronote
- Visual contrast showing data vs insights

### 5. Testimonials
- 3 testimonial cards from target personas
- Developer, Designer, Freelancer quotes

### 6. Pricing
- Simple: Free Trial + One-time Purchase ($49)
- Feature list
- Money-back guarantee

### 7. Footer
- Logo, navigation links, social icons
- "Made for Mac" badge

## Animation Strategy
- Smooth scroll reveal animations (fade-up)
- Subtle parallax on hero elements
- Hover states on cards (lift + glow)
- CTA button pulse animation
